# CreatorGuard

Premium SaaS platform for creator content protection with real-time leak detection, blockchain verification, and forensic analysis.

## Features

- **Real-Time Leak Detection** - Monitor 50+ platforms for content leaks
- **Watermarking** - Multi-layer forensic watermarking for images and videos
- **Blockchain Registry** - Polygon-based proof of ownership
- **Evidence Management** - Comprehensive forensic analysis and legal documentation
- **Analytics Dashboard** - Track leaks, revenue impact, and platform distribution

## Tech Stack

- React 18
- Tailwind CSS
- React Router
- Recharts
- Lucide Icons

## Getting Started

### Prerequisites

- Node.js 16+ and npm

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
```
